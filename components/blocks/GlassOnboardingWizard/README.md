# GlassOnboardingWizard

A beautiful, multi-step onboarding wizard component utilizing glassmorphism aesthetics. It includes progress tracking, animated step transitions, and interactive form elements.

## Preview

![GlassOnboardingWizard Preview](preview.webp)

## Usage

Copy \`GlassOnboardingWizard.jsx\` to your project. It requires Tailwind CSS and \`lucide-react\` for icons.

\`\`\`jsx
import GlassOnboardingWizard from './GlassOnboardingWizard';

export default function App() {
  return (
    <div className="p-8">
      <GlassOnboardingWizard />
    </div>
  );
}
\`\`\`
