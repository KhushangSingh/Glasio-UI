# Glasio UI Snippets

This is the official VS Code extension for [Glasio UI](https://glasio-ui.vercel.app), a beautifully crafted, zero-dependency glassmorphism UI library.

## Features

Type `glasio-` in your React/Next.js files and hit Tab or Enter to instantly insert the raw code for any component! 

For example:
- `glasio-glass-card`
- `glasio-custom-cursor`
- `glasio-glass-auth-block`

## Usage
These snippets are built for projects using **React** and **Tailwind CSS**. Make sure Tailwind CSS is installed in your project, and then copy and paste the components you need directly into your codebase.

## Support
For documentation and full component previews, visit our [Component Registry](https://glasio-ui.vercel.app).
